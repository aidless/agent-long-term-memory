# 判断①：长程自主性的失败率连乘衰减

> **核心判断**：多步工具调用、跨天自主、错误复合——每一步都有失败率，连乘起来指数级衰减。这是 agent 落地最卡的环节。

## 定义

长程自主性（long-horizon autonomy）指 agent 在**不依赖人工干预**的情况下，连续完成多步任务的能力。其核心度量是**任务完成率**对**步数**的依赖关系。

设单步成功率为 $p$，则 k 步任务的理论完成率为 $p^k$。当 $p < 1$ 时，完成率随 k 指数衰减：

| 单步成功率 p | 20 步 | 50 步 | 100 步 |
|---|---|---|---|
| 0.99 | 0.818 | 0.605 | 0.366 |
| 0.98 | 0.668 | 0.364 | 0.133 |
| 0.95 | 0.358 | 0.077 | 0.006 |
| 0.90 | 0.122 | 0.005 | 0.00003 |

> 表内数值由 `p^k` 计算，可复算。

## 为什么是核心问题

1. **指数衰减是结构性的**：即使单步成功率很高（0.98），50 步任务完成率仅 0.36。提高单步成功率的收益被连乘放大。
2. **错误复合**：错误不只降低单步成功率，还污染后续步骤的上下文/记忆，使 $p$ 随步数进一步下降——这是比简单连乘更坏的情况。
3. **跨天自主**：跨天任务引入了状态持久化、记忆失效、环境漂移，$p$ 本身不稳定。

> **判断①的直接实证**：文献[1] 实测可靠性衰减曲线，且发现「记忆脚手架普遍损害长时程性能（全部 10 模型）」——这与判断②「检索≠记忆」呼应：记忆脚手架反而有害。文献[2] 提供概念基础：long-horizon ≠ long-context ≠ long-term memory 三者区分，避免术语混淆。

## 缺口

1. **可靠性建模**：现有工作多聚焦单步或短链（k≤10），缺乏 k=50-100 的实测可靠性曲线。文献[1] 已覆盖 k=50-100 量级（四时长桶），但未给出**显式 p^k 模型拟合**——这是我们的切入点。
2. **错误复合模型**：缺少「错误→上下文污染→后续 p 下降」的定量模型。文献[1] 的 VAF 与文献[2] 的 trajectory-level diagnostics 提供方向，但无显式错误复合公式。
3. **记忆与长程可靠性的关系**：长期记忆系统能否提升长程任务完成率，缺乏对照实验证据（P6 正是为此设计的预注册，但未跑）。**文献[1] 发现 (5) 反而提示记忆脚手架有害**——这使 P6 的对照实验更有价值：记忆到底是有益还是有害？
